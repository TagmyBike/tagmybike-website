## ADDED Requirements

### Requirement: Correct nav link labels and targets
Navigation links SHALL correctly map to their target sections: Products → #accessories, Solutions → #solutions, Specs → #tech.

#### Scenario: Products link scrolls to accessories
- **WHEN** user clicks "Products" in the nav
- **THEN** the page scrolls to the #accessories section

#### Scenario: Solutions link scrolls to solutions
- **WHEN** user clicks "Solutions" in the nav
- **THEN** the page scrolls to the #solutions section

#### Scenario: Specs link scrolls to tech
- **WHEN** user clicks "Specs" in the nav
- **THEN** the page scrolls to the #tech section
